## What's new in mistri 1.2.0

- **Updates built in.** mistri checks for new versions once a day (you can turn this off) and installs them only after you agree, and only if the installer is signed by GITAV.
- **Signed by GITAV.** The installer and uninstaller carry GITAV's code signature, so Windows shows a verified publisher.
- **ClamAV setup inside the app.** Install ClamAV from the Security page or the installer: the download resumes if it stalls, and Cisco's signature is checked before it runs.
- New look: sidebar navigation, a Home dashboard, ⓘ explanations everywhere, and light and dark modes that stay sharp at any display scaling.
